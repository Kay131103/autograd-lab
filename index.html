WHAT IS AN AUTOGRAD ENGINE?

Every scalar in the network is a Value that remembers how it was created. Arithmetic (+, *, tanh…) builds a computation graph. Calling loss.backward() walks the graph in reverse topological order and applies the chain rule at every node — that's all backpropagation is.

THE CHAIN RULE, BY HAND

For c = a · b, the engine closes over:

  1. ∂c/∂a = b → a.grad += b.data * c.grad
  2. ∂c/∂b = a → b.grad += a.data * c.grad

The whole engine is src/engine.js — about 120 lines, view source.
